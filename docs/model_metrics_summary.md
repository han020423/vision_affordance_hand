## 0. 지표가 여러 개인 이유

| 지표 | 정의 | 용도 |
|---|---|---|
| mask mAP50 / mAP50-95, Precision, Recall | Ultralytics AP 평가 (인스턴스 단위) | 학습 실험 간 공식 비교 (같은 test/val 안에서만) |
| 픽셀 IoU (mean/median), 완전 누락 | conf 0.25 고정, 클래스별 합집합 마스크 대 GT | 계보(YOLO↔RF-DETR) 공통 프로토콜 비교, 시연 관점 진단 |
| F_β^w (weighted F-measure) | Margolin et al. 기준, affordance 문헌(UMD 계열) 표준 | 문헌과의 간접 대조 |
| 정책 감사 (functional-on-contain) | 컨테이너 117장에서 위반 이미지 수 | mAP가 못 보는 프로젝트 정책 오류 검출 |

mAP는 실험마다 valid/test 구성이 달라(§주의) 실험 간 직접 비교가 안 되는 경우가
있고, 그때는 GT를 고정한 픽셀 IoU를 쓴다.

## 8. 해석 주의사항

1. 모든 수치는 단일 실행이다. 실행 간 분산을 측정하지 못했으므로(보고서 5.6절)
   0.01 미만 차이로 우열을 말하지 않는다.
2. RF-DETR 학습 mAP는 valid 구성이 실험마다 달라 직접 비교하지 않는다. 실험 간
   비교는 GT 고정 픽셀 IoU만 쓴다.
3. robot_hand IoU의 GT는 SAM2 의사라벨의 사람 승인본이라 완전 수동 GT보다 관대하다.
4. v6 표적 항목(원통·검정)은 P의 학습 프레임이므로 P 수치는 낙관적 상한이다.
5. mug_04와 손 영상 속 파란 머그는 다른 실물이지만 외형이 비슷하다 —
   unseen-instance 해석 시 명시한다.
6. P의 접근 자세 GT 영상 실사 56장이 P의 valid에 포함되어 조기 종료 선택이 P에
   유리했을 수 있다.
7. F_β^w는 클래스 정의 차이로 문헌 수치와 직접 비교하지 않는다. 또 소프트 확률 맵을
   전제하는 지표라 이진 마스크를 내는 RF-DETR에는 임계값 민감성이 있다(0.15에서 최고).
8. 계열 비교(YOLO↔RF-DETR)는 4절의 validation이 아니라 7.5절의 test 수치를 쓴다.
   분할을 바꾸면 개선 요인의 해석이 달라진다.
