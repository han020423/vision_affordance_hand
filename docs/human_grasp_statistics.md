# 인간 파지 행동 통계 분석 (EPIC-KITCHENS VISOR)

교수님 피드백("물체를 보고 이렇게 파지한다는 근거가 필요하다 — EPIC-KITCHENS 참고")에
대응하는 분석이다. 파지 자세 매핑(손잡이→집기·감아쥐기, 몸통→움켜쥐기,
기능부→회피)의 타당성을 실제 인간 행동 데이터로 입증하고, 그 통계를 후보 선택
점수식의 사전확률로 활용한다.

## 방법

1. VISOR sparse 주석(158개 비디오, 40,604 프레임)에서 사람 주석자가 확정한
   손-물체 접촉 이벤트 53,605건 수집
2. 관심 물체 1층 13종(prior 산출용) + 보강 2층 7종(집기 근거용)으로 분류
   (이름 마지막 단어 일치, 설비·음식은 제외)
3. 비디오 라운드로빈 층화 추출로 895장면 선정 (seed 42, 참가자 편중 완화)
4. 렌더링된 오버레이(물체=노랑, 손=빨강 윤곽)를 보며 **사람이 전량 판정**
   (5분류: 손잡이/몸통/테두리·꼭지 집기/기능부 접촉/파지 아님) — 868장 완료
5. '파지 아님' 129건 제외 후 집계 (유효 739건, 1층 544건)

도구: `scripts/visor_select_samples.py`, `scripts/visor_render_judgment.py`,
`scripts/visor_judge_grasp.py`. 결과: `outputs/visor_judgment/stats_summary.json`,
`human_grasp_statistics.png`.

## 핵심 결과

| 물체군 | 인간 파지 행동 | 시스템 설계와의 대응 |
|---|---|---|
| 자루 도구(칼·국자·주걱·팬·주전자 등) | 손잡이 파지 91~100% | handle 영역 우선의 근거 |
| 병·유리컵·병조림 | 몸통 파지 92~100% | body→움켜쥐기(POWER)의 근거 |
| **머그 57%/43%, 컵 40%/57%** | 손잡이·몸통 혼용 | **복수 후보 유지 + 접근 방향 선택 설계의 직접 근거** |
| 접시·도마·뚜껑 | 테두리·꼭지 집기 62~96% | 집기(PRECISION) 계열의 행동 근거 |
| 기능부 접촉 | 전체 0.9% (칼날 0%) | functional 회피 정책의 행동적 근거 |

## 시스템 반영 (3안-라이트)

`configs/human_grasp_prior.yaml`의 3클래스 prior
(handle 0.763 / body 0.228 / functional 0.009)를 후보 선택 점수식에
`w_H·H_i` 항(초기 w_H=0.08)으로 주입한다. 물체 이름이 아니라 모델 클래스로
조회하므로 물체 인식이 필요 없고, 물체 이름 기반 규칙 금지 정책과도 충돌하지
않는다.

## 판정 신뢰성과 자세 관찰: AI 제2 판정자 전수 대조 (2026-08-26)

판정자 1인 한계를 보완하고 "자세" 근거를 직접 관찰로 확보하기 위해, **868장 전수**를
VLM(claude-fable-5)이 사람 라벨을 보지 않은 상태로 재판정했다. 부위(5분류)와
자세(PINCH/WRAP/POWER/TOUCH/NONE)를 함께 기록했다.

### 부위 판정 일치도 (사람 대 AI, 868장 전수)

- 5분류 전체: 일치 76.4% (663/868), Cohen's κ = **0.645** (substantial)
- **둘 다 파지로 판정한 691장의 부위 3분류: 일치 89.9%, κ = 0.820** (almost perfect)
- 불일치는 대부분 '이 접촉이 파지인가'(not_grasp 경계)와 식기류 handle/functional
  경계에 몰려 있다. 설계 통계에 쓰이는 부위 구분 자체는 거의 일치한다.

### 자세 직접 관찰 (AI 전수 판정, 868장)

부위와 자세의 대응이 매우 뚜렷하다.

| 부위 | n | 관찰된 자세 |
|---|---:|---|
| handle | 432 | **WRAP 68% / PINCH 32%** |
| body | 185 | **POWER 92%** / PINCH 8% |
| rim_pinch | 169 | **PINCH 99%** |

물체군별로도 프로젝트의 자세 규칙과 일치한다.

| 물체군 | 지배적 자세 |
|---|---|
| 팬 96%, 주전자 92%, 칼 83%, 국자 80%, 가위 71% | **WRAP** (감아쥐기) |
| 유리컵 96%, 병 85%, 컵 75% | **POWER** (움켜쥐기) |
| 냄비(귀 손잡이) 89%, 그릇 81% | **PINCH** (집기) |
| 머그 | PINCH 48% / POWER 43% — 갈림 |

핵심 관찰: **같은 "손잡이"라도 구조가 자세를 가른다.** 팬·주전자의 긴 자루는 WRAP(96%,
92%)인 반면, 냄비의 짧은 귀 손잡이는 PINCH(89%)다. 부위 이름이 아니라 부위의 기하가
자세를 결정한다는 종횡비 규칙(4절)이 전수 관찰로 재확인됐다.

한계: AI 판정자는 개별 라벨은 눈가림이지만 집계 분포 문서에 대한 사전지식이 있고,
사람과 완전히 독립적인 판정 과정은 아니다. 복수 사람 판정자 일치도는 향후 과제다.
결과 파일: `outputs/visor_judgment/ai_cross_check_20260826/full_pass_summary.json`
(전수 판정 `ai_full_pass.jsonl` 868건, 150장 눈가림 표본 대조 `agreement_summary.json`).

## 한계와 향후 연구

- 파지 선택은 작업(task) 의존적이다(마실 때 vs 옮길 때). 본 시스템은 접근
  방향이 1차 신호이고 prior는 동점 해소용 보조 신호로만 사용한다.
- 판정자 1인 통계다. 복수 판정자 일치도 측정은 향후 과제.
- VISOR 접촉 마스크에서 파지 영역·자세를 직접 학습(pseudo-label)하는 확장은
  가림 역설(잡힌 부위는 손에 가려짐)과 1인칭-외부 시점 도메인 격차 해결이
  필요한 후속 연구로 남긴다.
