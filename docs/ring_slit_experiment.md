# 고리형(절개선) 폴리곤 실험 (실험 I, 2026-08-19)

## 배경

YOLO 폴리곤 형식은 구멍 있는 마스크를 표현할 수 없어, 컵·그릇·팬처럼 contain
구멍을 두른 고리형 몸통 컴포넌트가 변환에서 제외되어 왔다 (공개 v2 기준 1,974개,
주로 body 클래스). 구멍을 채우면 contain을 몸통으로 학습하게 되어 정책 위반이므로,
**절개선(slit) 방식**으로 해결했다: 바깥 윤곽과 구멍 윤곽을 폭 0의 절개선으로 이어
단일 폴리곤로 만들되, 채웠을 때 구멍 내부는 배경으로 남는다.

## 구현

- `src/datasets/yolo_export.py`의 `component_to_yolo_polygon`에
  `allow_ring_slit` 옵션 추가 (`_bridge_ring_polygon`이 최근접 꼭짓점 쌍으로 연결)
- 재구성 IoU가 0.85 미만이면 안전하게 제외 (`ring_slit_reconstruction_iou_too_low`)
- 기본값은 꺼짐 — 기존 A~H 데이터셋의 재현성 불변
- 단위 테스트: 구멍 보존, 다중 구멍, 기존 동작 불변, IoU 게이트 (tests/test_ring_slit.py)

## 적용 결과 (export)

- 공개 v3: slit 3,525개 적용, IoU 미달 제외 0. body 인스턴스 3,074→4,521 (+1,447)
- 자체 v2: mug_02 가림 몸통 1개 복원 (grasp 인스턴스 266→267)
- v3는 train뿐 아니라 val/test 정답도 복원되므로, v2 test와의 수치 비교에는
  정답 불완전성 편향이 있다 (아래 참조)

## 학습·평가 (실험 I = v3 사전학습 → 혼합 v3 미세조정)

동일 v3 test 1,288장(복원된 완전한 정답) 기준 mask mAP50:

| 클래스 | H (절개선 없음) | I (절개선) |
|---|---:|---:|
| 전체 | 0.828 | **0.836** |
| body | 0.905 | **0.912** |
| handle | 0.708 | **0.730** |
| functional | **0.871** | 0.866 |

- 자체 val(mug_03): H 0.897 → I **0.910** (mAP50-95 0.712)
- contain 정책 감사: 두 모델 모두 위반 0/117
- 참고: v2 test(고리 몸통 정답 누락) 기준으로는 I 0.782로 H(0.792)보다 낮게
  측정되는데, 이는 I가 복원 몸통을 예측하면 v2 정답에 없어 오검출로 처리되는
  편향 때문이다. 공정 비교는 v3 test 기준을 사용한다.

## 결론

절개선 도입으로 body·handle·자체 머그 성능이 일관되게 향상됐고 정책 위반 없이
컨테이너 몸통 라벨 손실 문제가 해소됐다. **실험 I가 현재 최종 후보 모델이다.**
