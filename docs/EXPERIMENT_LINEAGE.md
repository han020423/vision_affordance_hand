# 실험 계보

2026-08-13부터 08-28까지 돌린 학습 실험 전체다. 폐기한 시도와 그 원인도 넣었다.
같은 실수를 반복하지 않는 것이 이 문서의 목적이다.

공통 조건은 seed 42다. YOLO 계보는 입력 640, AdamW, `lr0=0.0003`, patience 25,
보수적 증강을 쓴다. RF-DETR 계보는 입력 312, `lr=1e-4`, batch 8 × 누적 2, 조기 종료다.
비교하는 실험끼리는 초기 가중치나 데이터 외에 바꾸지 않았다.

## 계보가 갈리는 지점

두 계보는 시작점이 다르다. 이 차이를 모르고 비교하면 잘못 읽는다.

```
YOLO 계보    COCO → 공개 affordance 사전학습 → 자체+공개 혼합 미세조정
             (G → H → I)

RF-DETR 계보 COCO/DINOv2 → 자체+공개 혼합 미세조정
             (K → M → N → O → P)          ← 별도 사전학습 단계 없음
```

RF-DETR 계보도 공개 데이터를 본다. 미세조정 혼합에 replay로 들어 있다. 다만 **별도
사전학습 단계를 거치지 않는다.**

그래서 "H → K가 모델 교체 효과"라고 읽으면 안 된다. 아키텍처, 백본 사전학습, 사전학습
단계 구성, 입력 해상도(640 대 312)가 함께 다르다. **파이프라인 대 파이프라인 비교**다.
`docs/rfdetr_experiment.md`에도 같은 주의가 적혀 있다.

## 폐기한 실험 J — 자체 지표만 보면 못 잡는다

UMD에서 머그와 컵의 `grasp`/`wrap-grasp` 라벨이 물체마다 일관되지 않아, 그 충돌을
정리하고 다시 학습했다.

| 지표 | 값 |
|---|---|
| 자체 validation mAP50 | **0.902** (계보 최고 수준) |
| 공개 test 전체 mAP50 | 0.564 |
| 공개 test body mAP50 | **0.185** (재현율 0.065) |
| 컨테이너 정책 감사 | **116 / 117 위반** |

자체 지표만 봤으면 그대로 채택했을 실패다. 몸통 예측이 사실상 무너졌고, 컵 몸통을
회피 영역으로 칠하는 정책 위반이 거의 전 장면에서 나왔다.

**교훈**: 자체 지표·공개 지표·정책 감사를 함께 두어야 한다. 셋 중 하나만 보면 이런
붕괴가 통과한다. 이후 모든 실험에서 세 가지를 함께 확인한다.

## 실패한 실험 N — 좋은 숫자가 배포와 무관할 수 있다

로봇손이 파지 후보로 오검출되는 문제를 근본 해결하려고 분할 모델에 네 번째 클래스
`robot_hand`를 추가했다. 기존 1~3 클래스 정의와 라벨은 건드리지 않았다.

지표는 좋았다. `robot_hand` AP 0.957, 재현율 1.0, 픽셀 IoU 평균 0.92. 기존 3클래스도
공개 val에서 M과 동급이었다.

그런데 실전에서 손이 화면에 들어오는 순간, 학습에 동반됐던 파란 머그를 뺀 모든 물체
인식이 무너졌다. 파지 중의 닫힌 손은 검출조차 되지 않았다. 바로 롤백했다.

원인이 셋이었다.

- **검증 설계 실수** — valid에 손-물체 상호작용 장면이 한 장도 없었다. 좋은 숫자는
  진짜였지만 배포 상황과 무관한 진짜였다
- **데이터 협소** — 단일 세션, 단일 배경, 펼친 손, 물체는 파란 머그 하나뿐이었다.
  모델이 배경·물체와의 허위 상관까지 학습했다
- **의사라벨 거짓 음성** — 머그 프레임 61장 중 20장에서 M의 손잡이 신뢰도가 문턱(0.5)
  바로 아래라 handle 라벨이 잘렸고, 그 프레임들이 "보이는 손잡이 = 배경"을 가르쳤다.
  자기 예측을 라벨로 쓸 때의 확증 편향을 그대로 밟았다

**교훈**: 검증 세트가 배포 상황을 담고 있는지 먼저 확인한다. 그리고 자기 예측을 라벨로
쓸 때는 문턱 아래로 잘린 것이 거짓 음성이 되지 않는지 본다.

O와 P가 이 셋을 각각 교정한 것이다.

## O → P — 실물에서 드러난 것을 겨냥한 재촬영

O는 파란 머그 상호작용은 복구했지만 실물에서 세 가지 한계를 보였다.

1. 실제 파지 접근 자세(측면·손등·굽힘)의 `robot_hand` 미검출
2. 원통 물체(캔·물병·컵)를 `handle`로 오인
3. 검정 물체를 `robot_hand`로 오인

P는 이를 겨냥해 신규 4종을 촬영했다. 접근 자세 손 112장, 원통 286장(전부 body),
검정 물체 80장(`robot_hand` 네거티브 겸용), 실사 상호작용 56장(valid).

Copy-Paste 합성은 구 세대를 승계하지 않고 전체 손 조각 풀(구 155 + 신 217)로 재생성해
개방 손바닥 편중을 없앴다.

| 항목 | O | P |
|---|---:|---:|
| 원통 286장 body 완전 미검출 | 83 | **0** |
| 원통 286장 handle 오검출 | 120 (42%) | **6** |
| 접근 자세 105장 손 미검출 | 5 | **2** |
| 공개 functional 완전 누락 | 80 | **41** |

P는 15/50 epoch에서 조기 종료했고 최고 EMA segm mAP50-95는 0.6310이었다.

## 시도했으나 얻지 못한 것

**실행 간 분산 측정.** 같은 설정을 seed만 바꿔 여러 번 돌려 분산을 보려 했으나,
Ultralytics 8.3.163에서는 seed를 바꿔도 데이터 순서가 바뀌지 않았다. train 이미지 목록
순서를 바꾼 데이터셋(`ord43`, `ord44`)을 따로 만들어 재시도했지만 끝내 분산을 얻지
못했다.

서버에 `custom_finetune_{h,i}_grasp_type_{v2,v3}_{seed43,seed44,ord43,ord44}` 실행이
남아 있다. 다시 시도할 때 출발점이 된다.

**보고하는 모든 수치는 단일 실행이다.** 0.01 미만 차이는 우열 근거로 쓰지 않는다.
